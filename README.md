# 📖 Read & Build — 영어 원서 읽기 챌린지

영어 원서의 한 페이지를 **사진으로 찍어 올리거나**, 앱에 내장된 **무료 고전 영어 원서**를 바로 읽으면,
Google Gemini AI가 그 페이지를 읽고 **100% 영어로 된 학습 가이드**(요약 · 핵심 단어 · 문장 분석 ·
이해도 퀴즈)를 만들어 주는 웹앱입니다. 별표(⭐)로 저장한 단어는 **1일 → 3일 → 7일 → 14일 간격
반복 복습**으로 다시 만나게 되고, 연속 학습일(스트릭)·뱃지·진행상황 공유 기능으로 여러 명이
함께하는 **영어 원문 읽기 챌린지**를 운영할 수 있습니다.

**[Read & Build] 챌린지**는 4주(주 7일 인증)간 원서를 읽거나 들으면서, AI로 나만의 학습앱도
함께 빌드해보는 프로그램입니다. 이 저장소는 그 챌린지를 위해 두 가지를 더 갖추고 있습니다:

- 챌린지 기간 : **2026년 9월 10일(목) ~ 10월 7일(수), 4주 (28일)**
- 인증 : 주 7일, 매일 24시(KST) 마감 · 읽기 또는 듣기 중 택1
- 킥아웃 : 누적 미인증 6회부터 (4회부터 앱에 경고 표시)
- 앱 빌드 수업 : 주 1회 · 총 4회 (앱 기획 → 데이터베이스 → AI API → 배포)

- **Firebase 기반 다자 인증** — 참가자가 구글 계정으로 로그인하고 닉네임을 정한 뒤 매일
  "읽었어요/들었어요"를 인증하면 Firestore에 기록되고, 운영자는 관리자 화면에서 전체
  참가자의 인증 현황과 누적 미인증 횟수(6회부터 킥아웃 대상)를 한눈에 봅니다. Firebase를
  설정하지 않으면 이 기능은 그냥 숨겨지고 앱은 평소처럼 개인 학습 도구로만 동작합니다.
- **인증할 날짜 선택** — 자정 직후에 인증하다가 날짜가 하루 밀리는 문제를 막기 위해,
  참가자가 참여일~오늘 중 어느 날짜로 제출할지 직접 고를 수 있습니다. 다만 오늘이 아닌
  날짜는 이미 마감이 지난 상태라 미인증(X)으로 집계된다는 안내가 함께 뜹니다
  (philosophyAIEDU/260818comingssoni의 "지각 제출 처리 방식"과 같은 규칙입니다).
- **카카오톡 인앱 브라우저 안내** — 챌린지 링크는 대부분 카카오톡 단톡방으로 공유되는데,
  구글은 카카오톡 등 인앱 브라우저에서의 로그인을 정책적으로 막습니다. 이 앱은 인앱
  브라우저를 감지하면 로그인 버튼 대신 기본 브라우저로 여는 안내를 보여줍니다
  (카카오톡은 원클릭으로, 그 외 앱은 "다른 브라우저로 열기" 메뉴 안내로).
- **듣기 인증** — 원서 읽기가 부담스러우면 오디오만 들어도 인증됩니다. 라이브러리 원서에
  낭독 mp3를 붙이면 리더 화면에 재생 플레이어가 나타납니다.

> 학습 내용(요약·단어 설명·퀴즈 등)이 영어로만 제공되는 이유: 영어를 한국어로 번역하지 않고
> **영어를 영어로 이해하는 몰입 학습**을 위해서입니다. (이 README와 앱의 안내 문구처럼
> "사용 방법"을 설명하는 부분만 한국어입니다.)

> 디자인은 **필로소피 AI 교육**의 골든 옐로우 브랜드 컬러(크리미 골드 배경 + 다크 골드
> 포인트)를 따릅니다.

## ✅ 준비물

1. **Node.js** — [nodejs.org](https://nodejs.org)에서 LTS 버전을 설치하세요. (이미 있다면 건너뛰기)
2. **Gemini API 키 (무료)** — [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에 접속해
   구글 계정으로 로그인 후 **"Create API key"** 버튼을 누르면 키가 발급됩니다. 복사해 두세요.
   (내장된 고전 원서를 읽을 때도 학습 가이드 생성에는 이 키가 필요합니다.)

## 🚀 실행 방법 (3단계)

터미널(맥: 터미널 앱, 윈도우: 명령 프롬프트/PowerShell)을 열고, 이 폴더로 이동한 뒤:

```bash
# 1) 필요한 파일 설치 (처음 한 번만)
npm install

# 2) 앱 실행
npm run dev
```

3. 화면에 나오는 주소(보통 `http://localhost:5173`)를 브라우저로 열면 끝!
   첫 화면에서 복사해 둔 Gemini API 키를 붙여넣으면 바로 사용할 수 있습니다.
   홈 화면 상단의 **"Read & Build 이용 방법"**을 펼치면 전체 사용법을 한국어로 볼 수 있습니다.

### 📱 휴대폰에서 쓰고 싶다면

배포(아래 참고) 후 휴대폰 브라우저로 접속하면 카메라로 바로 페이지를 찍을 수 있습니다.
브라우저 메뉴에서 **"홈 화면에 추가"**를 누르면 일반 앱처럼 설치되며(PWA),
저장한 단어장과 복습 화면은 **오프라인에서도** 열립니다.

## 🎯 챌린지 핵심 기능

- **🚀 챌린지 안내 화면** — 앱을 처음 열면 챌린지가 스스로를 소개합니다. 무엇을 하는지(3가지
  축), 4주 커리큘럼, 챌린지 규칙(주 7일 인증 · 미인증 6회 킥아웃)까지 한 화면에 담겨 있고,
  홈 아래쪽 **"챌린지 안내 · 규칙"**으로 언제든 다시 볼 수 있습니다.
- **🏠 챌린지 대시보드** — 홈 화면이 지금 며칠차/몇 주차인지, 오늘 인증했는지, 이번 주 수업이
  무엇인지를 순서대로 보여줍니다. 시작 전에는 D-day 카운트다운이 표시됩니다.
- **🧑‍💻 4주 커리큘럼 화면** — 주 1회(월 4회) 진행하는 "AI로 나만의 학습앱 만들기" 수업을
  주차별로 보여줍니다 (앱 기획 → 데이터베이스 연동 → AI API 연동 → 배포). 지금 주차가
  강조되어, 이번 주에 무엇을 만드는지 바로 확인할 수 있습니다.
- **📷 Scan a Page** — 내가 읽는 책 한 페이지를 사진으로 찍어 AI 학습 가이드를 받습니다.
- **📖 Read the Library** — 계정·비용 없이 바로 읽을 수 있는 무료 고전 영어 원서 12종,
  영어 성경(World English Bible) 6권, 그리고 명대사 라이브러리 1종까지 총 19종이
  들어있습니다 (아래 목록 참고). Beginner(초록) · Intermediate(골드) · Advanced(자주)
  레벨별로 색상 구분되어 묶여 있고, 각 책마다 **챌린지 기간(28일) 기준 하루 페이지 수**가
  표시됩니다. 리더 화면에서도 지금이 28일 중 며칠째인지 확인할 수 있어요. 페이지를
  넘기며 읽다가 "Analyze this page"를 누르면 사진 없이 바로 학습 가이드가 만들어집니다.
- **💬 명대사 라이브러리** — 고전을 통째로 읽기가 부담스러운 분들을 위해, Beginner 섹션
  맨 위에 **"Great Lines from the Classics"** 한 권을 넣었습니다. 이 라이브러리에 있는
  12종 고전 원서에서 뽑은 유명한 한 문장씩을, 하루 한 편(Day 1~30) 30일 분량으로
  담았습니다. 저작권 문제가 전혀 없도록 **영화·드라마 대사는 넣지 않았고**, 모두 저작권이
  만료된 고전 문학에서 그대로(원문 그대로) 인용했습니다 — 자세한 내용은 아래
  [명대사 라이브러리](#-명대사-라이브러리-great-lines-from-the-classics) 참고.
- **🎧 듣기 인증** — 원문 읽기가 부담스러우면 들어도 됩니다. 책에 낭독 mp3를 붙여두면
  (아래 [듣기 파일 추가하기](#-듣기-파일-추가하기) 참고) 리더 화면에 재생 플레이어가 나타나고,
  다 들었으면 홈 화면에서 "들었어요"로 인증할 수 있습니다.
- **🔊 발음 듣기** — 단어 옆 스피커 아이콘을 누르면 브라우저 내장 음성으로 발음을 들을 수 있습니다.
- **✨ 현대식 영어로 보기** — 고전 원문은 thee/thou, shall, whilst 같은 옛 어휘·문장 구조가
  많아서 부담스러울 수 있어요. 리더 화면의 "📜 원문 그대로 / ✨ 현대식 영어" 토글을 누르면
  그 순간 보고 있는 페이지만 Gemini가 즉석에서 현대식 영어로 다시 써 줍니다 — 원하는
  사람만, 원하는 페이지만 바꿔 보는 방식이라 책 전체를 미리 변환해 둘 필요가 없습니다.
  같은 페이지를 다시 열면 기기에 저장된 결과를 바로 보여줘서 API를 다시 호출하지 않습니다.
- **📖 단어 탭하면 바로 사전** — 리더 화면의 본문은 단어 하나하나가 탭 가능합니다. 모르는
  단어를 탭하면 그 문장 속 의미를 Gemini가 바로 풀이해주고, 마음에 들면 그 자리에서 별표로
  단어장에 저장할 수 있습니다 — 전체 페이지 분석을 돌리지 않아도 됩니다.
- **📝 내 메모** — 리더 화면 하단의 "내 메모"에 책마다 자유 메모장이 하나씩 있습니다. 읽으며
  모르는 단어나 생각을 적어두면 자동으로 이 기기에 저장됩니다.
- **👥 챌린지 인증 & 운영자 대시보드** — Firebase를 설정하면(아래 [Firebase 설정
  방법](#-firebase-설정-방법-챌린지-인증) 참고), 참가자가 **구글 로그인 후 닉네임만 정하면
  스스로 등록**되고 매일 읽기/듣기 인증을 제출합니다. 운영자는 참가자 화면과 완전히 분리된
  전용 대시보드(설정 탭 → "운영자이신가요?")를 갖습니다 — 상단에 참가자 수·오늘 인증·위험군·
  킥아웃 대상을 한눈에 보여주는 통계 헤더가 있고, **일일현황**(전체 참가자 O/X/P 매트릭스),
  **명단 관리**(면제일 등록, 킥아웃/복귀 처리), **공지 문구**(아래) 세 탭으로 나뉩니다.
  계정으로 본인이 확인되므로 남의 이름으로 인증할 수 없습니다. Firebase를 설정하지 않으면
  이 기능은 자동으로 숨겨집니다.
- **💬 공지 문구 자동 생성 & 복사** — 운영자 대시보드의 "공지 문구" 탭이 오늘 날짜·Day 번호·
  이번 주 앱 빌드 수업 정보로 카카오톡에 바로 붙여넣을 공지 문구를 자동으로 만들어줍니다.
  자유롭게 고친 뒤 **복사하기** 버튼 한 번으로 클립보드에 담겨서, 단톡방에 붙여넣기만 하면
  됩니다. (`challengeConfig.js`의 `appUrl`을 채우면 인증 링크도 함께 들어갑니다.)
- **📊 영어 레벨 테스트** — 설정 탭에서 6문항 테스트로 내 레벨(Beginner/Intermediate/Advanced)을
  확인하면, 학습 가이드의 어휘 난이도와 라이브러리 추천 도서가 그에 맞게 조정됩니다.
- **🔥 스트릭 & 뱃지** — Progress 탭에서 연속 학습일, 완독한 챕터/책 수, 저장한 단어 수에 따른
  뱃지를 확인할 수 있습니다.
- **✅ 체크 & 공유** — 홈 화면의 "오늘 학습 완료 체크 & 공유" 버튼을 누르면 챌린지 인증 이미지가
  만들어져 바로 저장하거나 공유할 수 있습니다.
- **🖨️ 인쇄하기** — 학습 결과 화면 상단의 Print 버튼으로 요약·단어·퀴즈뿐 아니라 **원본
  내용(스캔한 사진 또는 라이브러리 원문)까지 함께** 깔끔한 인쇄용 레이아웃으로 출력할 수
  있습니다.
- **🤝 단어장 함께 쓰기** — Word Book의 "Share Deck"으로 단어 목록을 파일로 내보내고, 챌린지
  멤버가 "Import Deck"으로 가져와 같은 단어를 함께 복습할 수 있습니다.

### 🌱 초보자를 위한 읽기 지원

- **레벨별 페이지 길이** — Beginner 책은 한 "페이지"가 더 짧게(약 150단어) 나뉘어서, 매번의
  읽기 세션이 부담스럽지 않아요. Intermediate는 220단어, Advanced는 280단어 기준입니다.
- **글자 크기 조절** — 리더 화면 상단의 A−/A+ 버튼으로 글자 크기를 4단계로 키울 수 있고,
  선택한 크기는 기기에 저장되어 다음에 열어도 유지됩니다.
- **예상 소요 시간** — 각 페이지 위에 "~N min read"로 대략적인 읽기 시간이 표시됩니다.
- **초보자 팁 배너** — Beginner 레벨 책을 펼치면 "모르는 단어가 나와도 괜찮아요" 같은 격려
  메시지가 리더 화면에 함께 표시됩니다.
- **컬러풀한 책 표지** — 라이브러리의 19권이 각자 다른 색·이모지 표지를 가져서, 실제
  책방처럼 마음에 드는 책을 눈으로 골라볼 수 있어요. 처음이라면 "처음이신가요?" 배너에서
  추천하는 가장 쉬운 책부터 시작하면 됩니다.
- **한눈에 보는 난이도·시간** — 각 책 카드에 "하루 ~N분", "28일 완독", 난이도 점(●○○)이
  표시되어 부담 없이 고를 수 있습니다.

### 💬 명대사 라이브러리 (Great Lines from the Classics)

고전 한 권을 통째로 읽는 게 부담스러운 분들을 위해, Beginner 섹션 **맨 위**에
"Great Lines from the Classics" 한 권을 추가로 넣었습니다. 아래 [내장 무료 원서
목록](#-내장-무료-원서-목록-모두-저작권-만료-공개-도메인) 12종에서 뽑은 유명한 한 문장씩을
"Day 1"부터 "Day 30"까지, 하루 한 편(문장 + 출처)씩 30일 분량으로 담았습니다.

- **영화·드라마 대사는 넣지 않았습니다.** 대부분 저작권이 살아있는 저작물이라, 여러
  작품의 대사를 모아 앱에 통째로 넣는 건 저작권 문제가 될 수 있습니다. 대신 이 저장소에
  이미 원문 그대로 들어있는, 저작권이 만료된 고전 문학(1813~1925년 작품, 저자 모두
  사후 70년 이상 지남)에서만 뽑았습니다.
- 각 문장은 라이브러리에 이미 있는 해당 책의 `public/books/<id>.json` 원문에서 그대로
  가져온 것이라 오탈자나 오역 없이 정확합니다 — 새로 타이핑하거나 기억에 의존하지 않고,
  실제 파일 내용을 검색해서 정확히 일치하는 문장만 사용했습니다.
- `scripts/build-books.mjs`의 `great-lines` 항목(`kind: 'inline'`)에 30개 문장이 그대로
  적혀 있어서, 문장을 추가·수정하고 싶으면 그 배열만 고친 뒤
  `node scripts/build-books.mjs --only=great-lines`를 실행하면 됩니다 (네트워크 요청 없이
  바로 반영됩니다).
- 이미 완성된 짧은 인용문이라 "✨ 현대식 영어" AI 변환 대상이 아니고
  (`noModernize: true`), `scripts/modernize-books.mjs`도 자동으로 건너뜁니다.
- 각 페이지에서도 다른 책과 똑같이 "Analyze this page"를 눌러 그 문장에 대한 AI 학습
  가이드(뜻풀이·단어·퀴즈)를 받을 수 있고, 원문 복사 버튼으로 문장만 바로 복사할 수도
  있습니다.

### 📖 영어 성경 목록 (World English Bible, 공개 도메인)

원서 읽기 대신 **영어 성경**으로 인증하고 싶은 분들을 위해, 가장 많이 읽히는 6권을
따로 넣었습니다. 66권 전체가 아니라 이 6권만 들어있습니다. 번역본은
**World English Bible(WEB)** — [worldenglish.bible](https://worldenglish.bible/)에서
Rainbow Missions, Inc.가 퍼블릭 도메인으로 공개한 현대 영어 번역으로, KJV(흠정역)처럼
저작권 걱정 없이 쓸 수 있으면서도 thee/thou 같은 옛 영어가 없어 바로 읽기 편합니다.
텍스트는 절 단위로 구조화된 공개 미러인
[midvash/bible-data](https://github.com/midvash/bible-data)에서 가져와, 각 절을
"절 번호 + 본문" 그대로(예: `16 For God so loved the world, …`) 문단으로 만들었습니다 —
사람이 손으로 옮기거나 요약하지 않고 원문 그대로 담았기 때문에 내용이 KJV처럼 변형되거나
누락될 걱정이 없습니다. 이미 현대 영어라서 다른 고전 원서와 달리 "✨ 현대식 영어" AI 변환
토글은 뜨지 않습니다 (`scripts/modernize-books.mjs`도 `bible: true`가 붙은 항목은 자동으로
건너뜁니다 — AI로 성경 본문을 다시 쓰면 의미가 달라질 위험이 있기 때문입니다).

| 레벨 | 책 | 챕터 | 28일 기준 하루 페이지 |
|---|---|---|---|
| 🟢 Beginner | John (요한복음) | 21 | ~6 |
| 🟢 Beginner | Proverbs (잠언) | 31 | ~5 |
| 🟡 Intermediate | Genesis (창세기) | 50 | ~8 |
| 🟡 Intermediate | Psalms (시편) | 150 | ~10 |
| 🟡 Intermediate | Matthew (마태복음) | 28 | ~5 |
| 🟣 Advanced | Romans (로마서) | 16 | ~2 |

"28일 기준 하루 페이지"는 그 책을 28일(4주) 챌린지 안에 완독하려면 하루에 몇 "페이지"
(레벨별 150~280단어 단위)를 읽어야 하는지 보여줍니다. 챌린지 그룹의 속도에 맞는
책을 고를 때 참고하세요.

새 책을 추가하려면 `scripts/build-books.mjs`의 `BOOKS` 목록에 항목을 추가하고
`node scripts/build-books.mjs`를 실행하세요 (새로 추가한 책만 다시 받고 싶다면
`node scripts/build-books.mjs --only=새책id`처럼 실행하면 나머지 책은 다시 내려받지
않고 캐시된 `public/books/*.json`을 그대로 씁니다). `public/books/*.json`이 새로
생성됩니다.

### ✨ 현대식 영어로 보기

책 전체를 미리 변환해 두는 별도 작업은 없습니다 — 리더 화면의 "📜 원문 그대로 / ✨ 현대식
영어" 토글을 누르면, **지금 보고 있는 페이지만** 그 자리에서 Gemini가 현대식 영어로 다시
써서 보여줍니다 (내 Gemini API 키를 그대로 사용하며, 학습 가이드를 만들 때와 같은
"페이지 단위" 호출입니다). 결과는 기기에 저장되어(`readmate` IndexedDB의 `modernPages`
스토어) 같은 페이지를 다시 열 때는 API를 다시 호출하지 않습니다. 다른 참가자와 공유되지
않는, 각자 기기별 캐시입니다.

영어 성경 6권(`bible: true`)과 "Great Lines from the Classics" 인용구 모음
(`noModernize: true`)에는 이 토글이 아예 나타나지 않습니다 — 성경은 이미 현대 영어(WEB)
번역이라 다시 쓸 이유가 없고, 인용구 모음은 원문 그대로 인용하는 게 핵심이라 AI가 바꿔
쓰면 안 되기 때문입니다.

## 🔥 Firebase 설정 방법 (챌린지 인증)

이 기능은 [필로소피 AI 교육의 "퍼스널메이커스 독서 챌린지" 인증 시스템](https://github.com/philosophyAIEDU/260818comingssoni)과
같은 구조(Firestore 컬렉션·킥아웃 판정 로직)로 만들어졌습니다. `src/lib/challengeConfig.js`의
`firebase.projectId`가 비어 있으면 관련 화면이 전부 자동으로 숨겨지므로, 설정 전까지는 아무것도
바뀌지 않습니다.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트를 만듭니다. (기존
   `260818comingssoni` 프로젝트와는 **별도 프로젝트**를 새로 만드는 걸 권장합니다 — 챌린지
   기간·킥아웃 기준·참가자 명단이 서로 다르기 때문입니다.)
2. **Firestore Database**를 활성화합니다 (프로덕션 모드, 리전은 `asia-northeast3` 등 가까운 곳).
3. **Authentication → Sign-in method**에서 **Google** 로그인을 사용 설정합니다 — 참가자
   본인 인증과 관리자 로그인 모두 이 하나로 처리됩니다.
4. **프로젝트 설정 → 일반 → 내 앱**에서 웹 앱(`</>`)을 추가하고, 표시되는 `firebaseConfig` 값을
   복사합니다.
5. `src/lib/challengeConfig.js`를 열어:
   - `firebase` 객체에 4번에서 복사한 값을 붙여넣고,
   - `startDate` / `endDate`를 실제 챌린지 기간으로,
   - `adminEmails`에 운영진 구글 계정을 추가합니다.
6. **Firestore 보안 규칙**을 설정합니다 (콘솔의 Firestore → 규칙 탭). 참가자가 구글 계정으로
   로그인하므로, 규칙에서 "본인 것만 쓸 수 있음"을 강제할 수 있습니다:

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       function isAdmin() {
         return request.auth != null &&
           request.auth.token.email in ['warmcomfortforyou@gmail.com'];
       }

       // 참가자 문서의 ID = 그 사람의 구글 계정 uid
       match /participants/{uid} {
         allow read: if request.auth != null;
         // 참여 등록·닉네임 변경은 본인만
         allow create, update: if isAdmin() || request.auth.uid == uid;
         allow delete: if isAdmin();
       }

       // 인증 기록 ID = "{uid}_{날짜}" → 하루 한 건, 본인만 작성
       match /submissions/{id} {
         allow read: if request.auth != null;
         allow create, update: if isAdmin() ||
           (request.auth != null && request.resource.data.participantId == request.auth.uid);
         allow delete: if isAdmin();
       }
     }
   }
   ```

   > 참가자마다 구글 계정이 확인되므로 **다른 사람 이름으로 인증을 제출할 수 없습니다.**
   > (명단을 미리 등록하고 이름만 고르던 이전 방식에서는 막을 수 없던 부분입니다.)

7. **배포 후**에는 Firebase 콘솔의 **Authentication → 설정 → 승인된 도메인**에 배포 도메인(예:
   `your-app.netlify.app`)을 추가해야 관리자 Google 로그인 팝업이 동작합니다.
8. 배포된 앱을 열면:
   - **홈 화면**의 "챌린지 참여하기" 카드에서 참가자가 **구글 로그인 → 닉네임 설정**을 하면
     바로 참여됩니다. 운영자가 명단을 미리 등록할 필요가 없습니다.
   - **설정 탭** 맨 아래 "운영자이신가요?" 카드에서 운영진 계정으로 로그인하면 관리자
     대시보드가 열리고, 일일현황·누적 미인증·킥아웃 대상을 확인하고 면제일을 등록할 수 있습니다.

## 🔒 개인정보

- API 키, 단어장, 학습 기록(스트릭·진행상황)은 **내 브라우저(IndexedDB)에만** 저장됩니다.
  외부 서버로 전송되지 않습니다.
- API 키는 오직 Google Gemini API 호출에만 사용됩니다.
- 업로드한 책 사진은 IndexedDB나 디스크에 **저장되지 않습니다.** 분석 후 결과 화면에서
  요약과 함께 확인하거나 인쇄(Print)할 수 있도록 그 화면을 보는 동안만 메모리에 남아있고,
  다른 화면으로 이동하면 즉시 사라집니다.
- "체크 & 공유"로 만든 이미지에는 책 원문이나 개인정보가 들어가지 않으며, 저장·공유 여부는
  전적으로 사용자가 직접 선택합니다.
- 광고 · 추적 스크립트가 전혀 없습니다.
- **Firebase가 설정된 경우에만 예외입니다**: 챌린지에 참여하면 **구글 계정으로 로그인**하게
  되고, 그 계정의 **닉네임과 이메일 주소**, 그리고 직접 제출한 **"날짜 · 읽었는지/들었는지 ·
  (선택) 책 제목"**이 Firestore에 저장됩니다. 닉네임과 인증 여부는 같은 챌린지 참가자에게도
  보이고, 이메일은 운영진이 관리자 화면에서 확인합니다(연락·킥아웃 안내용). 읽은 페이지
  내용이나 단어장·사진은 **저장되지 않습니다** — 여전히 이 기기에만 남습니다. Firebase를
  설정하지 않으면 이 문단은 해당 사항이 없습니다.

## ❓ 자주 묻는 질문

- **분석이 실패해요** → 페이지 전체가 선명하게 나오도록 다시 찍어 보세요. 네트워크/일시 오류는
  자동으로 최대 2회 재시도합니다. 키 오류라면 설정(⚙️) 탭에서 키를 다시 확인하세요.
- **단어 내보내기는 어떻게 하나요?** → 단어장(📚) 탭 상단의 **Anki (CSV) / Quizlet (TXT)** 버튼을
  누르면 파일이 다운로드됩니다. **Share Deck**은 Read & Build 전용 형식(JSON)으로, 다른 챌린지
  멤버가 **Import Deck**으로 그대로 가져와 같은 단어를 복습할 수 있습니다.
- **복습 간격은 어떻게 정해지나요?** → Leitner 상자 방식입니다. 새 단어는 1일 뒤에 나타나고,
  `Good`을 누를 때마다 3일 → 7일 → 14일 → 30일로 늘어납니다. `Hard`는 처음(1일)으로 되돌리고,
  `Easy`는 한 단계 건너뜁니다.
- **스트릭은 어떻게 계산되나요?** → 사진 분석, 라이브러리 페이지 분석, "체크 & 공유" 중 하나라도
  한 날짜에 있으면 그날은 "활동한 날"로 기록됩니다. 오늘 아직 아무것도 안 했어도 어제까지의
  스트릭은 자정이 지나기 전까지 유지됩니다.
- **레벨 테스트 결과는 어디에 쓰이나요?** → 학습 가이드의 어휘 난이도(Gemini 프롬프트)와
  라이브러리의 "Recommended for you" 표시에 반영됩니다. 설정 탭에서 언제든 다시 볼 수 있습니다.
- **28일 완독 플랜은 강제인가요?** → 아니요, 참고용 안내입니다. 그 책을 챌린지 기간(28일) 안에
  끝내려면 하루 몇 페이지씩 읽어야 하는지 계산해서 보여줄 뿐이고, 리더
  화면의 "Day X of 28"도 지금 읽은 양 기준으로 계산되는 참고 지표입니다. 실제 진도는
  자유롭게 조절하면 됩니다.
- **챌린지 인증과 개인 스트릭은 다른 건가요?** → 네. 홈 화면 상단의 "[Read & Build] 챌린지 인증"
  카드(Firebase 설정 시에만 보임)는 운영자가 킥아웃 판정에 쓰는 **공식 인증**이고, 그 아래
  "체크 & 공유"는 개인 스트릭·공유 이미지를 위한 **로컬 전용** 기능입니다. 챌린지 인증을 하면
  로컬 스트릭에도 자동으로 반영되지만, 반대로 "체크 & 공유"만 눌러서는 챌린지 인증이 되지
  않습니다 — 반드시 인증 카드의 "오늘 인증하기"를 눌러야 Firestore에 기록됩니다.
- **미인증이 몇 번이면 킥아웃인가요?** → `src/lib/challengeConfig.js`의 `kickoutThreshold`(기본
  6회)입니다. `riskThreshold`(기본 4회)부터는 "위험" 경고가 먼저 표시됩니다. 오늘은 24시
  마감 전이라 아직 미인증으로 확정되지 않으며, 판정 기준 시간대는 `timezone`(기본
  `Asia/Seoul`)입니다.
